## В очереди

### 1. Локальный SEO-аудитор (без внешних API)

**Приоритет:** высокий
**Сложность:** средняя
**Файл:** `_scaffold/seo-audit.cjs`

Node.js-скрипт который ОФЛАЙН (без API, мгновенно) проверяет после сборки:

- **Плотность ключевых слов** — считает вхождения бренда, «ставки», «казино», «бонус», «тенге» по абзацам и на страницу. Сравнивает с лимитами из CONTENT_GUIDE (бренд max 1/абзац, max 8-10/страница)
- **Водность** — считает процент стоп-слов из нашего списка (из CONTENT_GUIDE). Стоп-слова: «также», «кроме того», «помимо», «при этом», «конечно же», «безусловно», «определённый», «соответствующий» и т.д.
- **Длина текста** — слов на странице. Лимит: главная 1000-1400, подстраницы 500-800
- **Уникальность title** — нет дубликатов между страницами
- **H1 не равен title** — проверяет что не совпадают дословно
- **Перелинковка** — считает внутренние ссылки `<a href="/...">` на каждой странице (минимум 3)
- **Alt-теги** — все `<img>` имеют alt, alt содержит кириллицу
- **Meta description** — есть, уникальный, длина 80-160 символов
- **Длина предложений** — считает среднюю длину и вариацию (если все одинаковые — WARN)
- **Повторение начал абзацев** — если 2+ абзаца начинаются с одного слова — WARN

Вывод: цветная таблица PASS/FAIL/WARN по каждой странице + общий скор.

Заменяет text.ru для 80% проверок. Text.ru оставить для финальной проверки уникальности.

### 2. Скрипт деплоя на хостинг

**Приоритет:** низкий (пока деплоим вручную)
**Сложность:** средняя
**Файл:** `_scaffold/deploy.sh`

Автоматизирует загрузку dist/ на хостинг:
- Принимает путь к проекту и данные хостинга (FTP/SFTP)
- Загружает файлы
- Проверяет что сайт открывается (curl HTTP 200)
- Опционально: меняет robots.txt на Allow
- Опционально: отправляет sitemap в Google Search Console через API

### 3. Мониторинг задеплоенных сайтов

**Приоритет:** низкий
**Сложность:** средняя

Скрипт который проверяет статус задеплоенных сайтов:
- Берёт список доменов из REGISTRY.md
- curl каждый домен → HTTP status code
- Проверяет SSL сертификат
- Проверяет что robots.txt открыт (если сайт запущен)
- Выводит таблицу статусов

### 4. A/B тестирование title/description

**Приоритет:** низкий
**Сложность:** высокая

Система для хранения вариантов title/description и отслеживания CTR через GSC API. Для будущего масштабирования.

### 5. Генератор отчётов по проекту

**Приоритет:** низкий
**Сложность:** средняя

Скрипт который по готовому проекту генерирует отчёт:
- Количество страниц, изображений, слов
- SEO-метрики (title, description, alt-теги)
- Результаты text.ru (если есть)
- Чеклист из VARIATION_STRATEGY
- Экспорт в PDF или HTML

### 6. Библиотека SVG-иконок

**Приоритет:** низкий
**Сложность:** низкая
**Файл:** `_scaffold/icons/`

Набор 30-40 SVG-иконок для карточек (спорт, казино, оплата, бонусы и т.д.). Сейчас агент каждый раз придумывает SVG-пути с нуля — часто получаются одинаковые. Библиотека ускорит и разнообразит.

### 7. Мультиязычность (казахский язык)

**Приоритет:** низкий (на будущее)
**Сложность:** высокая

Некоторые сайты на казахском языке для расширения охвата. Потребует:
- Перевод CONTENT_GUIDE на казахский
- FAQ на казахском
- Отдельные ключевые слова
- `<html lang="kk">`

### 8. Интеграция с Google Search Console API

**Приоритет:** низкий (когда будет 10+ задеплоенных сайтов)
**Сложность:** высокая

Автоматическая отправка sitemap, запрос индексации, мониторинг позиций через GSC API.
