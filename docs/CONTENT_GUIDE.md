# Гайд по написанию контента

> Все тексты на сайтах должны быть неотличимы от написанных реальным человеком.
> Ни один AI-детектор не должен распознать генерацию.

---

## Активный формат — ТОЛЬКО `H` (Премиум-энциклопедия в стиле BC.Game)

С этого момента **все новые проекты пишутся только в формате H**. Старые форматы A-G законсервированы (см. конец файла, секция «Стилистики контента по форматам»).

Решение принято после анализа конкурента [bc-game-brazil.com](https://bc-game-brazil.com/) — длинные энциклопедические страницы с большим объёмом текста, многочисленными изображениями и повторяющимися промо-баннерами дают лучшее SEO-покрытие, удержание и конверсии партнёрской ссылки.

### Главный принцип формата H

Сайт пишется как **подробный энциклопедический обзор онлайн-казино/беттинг-площадки** в духе bc-game-brazil.com:

- Тон — нейтральный, **3-е лицо платформы + прямое обращение «вы» к читателю**: «{brand} предлагает игрокам...», «Вы можете легко пополнить счёт через...»
- Это **не личный блог** и **не корпоративный сайт-визитка**. Это длинный обзор-энциклопедия с маркетинговым уклоном
- Главная страница — **3000-4000 слов**, 12-15 H2-секций
- Подстраницы — **1500-2500 слов**, 8-10 H2-секций
- **15-20 заглушек изображений** на главной странице (1-2 в каждой H2-секции)
- **Повторяющийся промо-баннер** после каждых 2-3 секций (5-7 раз на главной)
- **Сводная таблица параметров** платформы в Hero/начале страницы
- **Таблица VIP-уровней** или таблица бонусов на 4 депозита где-то на главной
- **Нумерованные пошаговые инструкции** (регистрация, депозит, вывод)
- **Bullet-списки** для преимуществ, способов оплаты, security features
- **FAQ** в конце с 4-6 вопросами и развёрнутыми ответами

### Что НЕ делаем в формате H

- Не пишем от 1-го лица: ❌ «Я скачал APK и проверил», ✅ «Скачайте APK и установите на ваше устройство»
- Не используем разговорные вставки «ну», «короче», «блин», «лично мне» — это маркеры формата A
- Не делаем субъективных оценок и личных историй автора
- Не делаем коротких страниц меньше 3000 слов на главной
- Не делаем 1-2 изображения на странице — нужно 15-20 на главной

### Что обязательно есть

- 3-е лицо + «вы»-обращение
- Развёрнутые абзацы (3-6 предложений), таблицы, списки
- Эмодзи-маркеры в сводной таблице параметров (✅ 📃 🎮 🃏 🎲 🎰 🔢 🎁 💳 💰 ⌛ 📱 📞)
- Бейджи доверия: «Проверено», «Использовано N минут назад», «Подробнее»
- Кнопки скачивания приложения (Android + iOS) под каждым промо-баннером
- Местные реалии региона (тенге, Kaspi, Halyk и т.п. — из `docs/REGIONS.md`)
- Финальный блок с рейтингом 4.9/5 и итоговой кнопкой

### Обязательные генерируемые визуальные ассеты

Для формата H **всегда генерируются 5 реальных ассетов** через `GenerateImage` (плюс ручной SVG-favicon). Подробные промпты и pipeline — в `docs/PROJECT_REQUIREMENTS.md`, секция 8.

| Ассет                                         | Кратко                                                |
| --------------------------------------------- | ----------------------------------------------------- |
| `public/images/hero.jpg`                      | Премиум-постер главного экрана (1376×768, JPEG)       |
| `public/images/logo.png`                      | Иконка-логотип для шапки/футера (256×256, PNG)        |
| `public/favicon.svg`                          | Ручной упрощённый SVG (читается в 16×16)              |
| `public/favicon.png` + `apple-touch-icon.png` | PNG-fallback из icon-style картинки (64×64 + 180×180) |
| `public/og-default.jpg`                       | Та же hero-картинка ужатая до 1200×630 для соцсетей   |

**Самодельные inline SVG в Header/Footer вместо `<img>` запрещены** — в маленьком размере они выглядят грубо. **CSS-градиенты вместо Hero-фона запрещены** — формат H требует премиум-постер как у BC.Game.

### Внешние ссылки — всегда `#` до этапа деплоя

**Все ссылки за пределы домена проекта подставляются как `"#"`.** Это касается всех CTA-кнопок в шапке, футере, hero, промо-баннерах, FAQ и финальных блоках. Реальные партнёрские URL подставляются позднее при деплое одной командой `sed -i 's|"#"|"https://..."|g'`. Подробное правило — в `docs/PROJECT_REQUIREMENTS.md`, секция 6, блок «Внешние ссылки».

В коде во всех страницах и компонентах:

```astro
const affiliateLink = '#'; // TODO: реальный URL при деплое
```

Внутренние ссылки на собственные страницы (`/registraciya`, `/bonus`, `/about`) — оставляем как обычно. Это правило только про уход трафика на внешний ресурс.

## Обязательные элементы текста

### 1. Местные реалии (по региону из конфига)

Все данные берутся из `docs/REGIONS.md` по полю `region` в конфиге проекта.

В каждом тексте должны быть упоминания:

- **Банки:** из таблицы региона (не просто «банковская карта», а конкретные: Kaspi / Uzcard / Kapital Bank...)
- **Провайдеры:** из таблицы региона (Kcell / Ucell / Azercell...)
- **Валюта:** название + код + символ из таблицы (использовать все три формы)
- **Города:** из таблицы региона (конкретные города, не абстрактно)
- **Спорт:** лига + клубы + сборная из таблицы региона
- **Культурные маркеры:** документ ID из таблицы (ИИН / ПИНФЛ / ФИН...)
- **Разговорные маркеры:** характерные для русскоязычных жителей конкретного региона

### Антиспам названия страны

Название страны НЕ должно повторяться чрезмерно:

- **H1 главной:** 1 раз (в формате `{brand} {страна}`)
- **Весь body text главной:** max 3-4 раза
- **Подстраницы:** max 1-2 раза на страницу

Вместо прямого названия страны использовать:

- «у нас», «в стране», «для местных игроков»
- Конкретный город: «из Алматы» вместо «из Казахстана»
- Конкретный банк: «через Kaspi» вместо «казахстанская карта»
- Валюту: «в тенге» вместо «в казахстанской валюте»
- Косвенные маркеры: провайдер, лига, клуб

### 2. Честные минусы (на каждой странице)

Примеры минусов, которые можно использовать (чередовать между проектами):

- Верификация затягивается на 3-5 дней
- Kaspi иногда отклоняет платежи
- Сайт блокируют Kcell и Beeline
- Интерфейс перегружен для новичков
- Вейджер ×35 на казино-бонус — жёстко
- Вывод на карту — до 3 рабочих дней
- APK не обновляется автоматически
- Поддержка отвечает шаблонно
- На KPL роспись беднее, чем на АПЛ
- Приложение тормозит на старых телефонах

### 3. Конкретные цифры (фактологические, без личного опыта)

В формате H — конкретные цифры даём как факты платформы, не как личный опыт. Без «я закинул», без «мне пришло».

```
«Минимальный депозит — 1 000 тенге через Kaspi»
```

## Техники антидетекта

### Burstiness (перемежение длины)

Чередовать:

- Длинные аналитические абзацы (5-7 предложений)
- Короткие эмоциональные реплики (1-2 предложения)
- Односложные оценки: «Норм.» / «Не фонтан.» / «Пойдёт.»

Пример:

> «В целом роспись на КПЛ выглядит прилично — основные рынки на месте, тоталы, форы, угловые. На матчи «Астана» — «Кайрат» роспись шире, до 150+ рынков, что для нашей лиги неплохо. Маржа 4-5% на топ-события, на аутсайдеров выше.
>
> Но вот лайв — тут есть нюансы.»

### Perplexity (неожиданные элементы)

- Неожиданные сравнения: «интерфейс как витрина базара — всё есть, но найти нужное сложно»
- Культурные отсылки: «как с Kaspi QR — вроде удобно, но половина терминалов не работает»
- Перескоки мысли: обсуждаешь бонусы → внезапно про погоду в Астане
- Субъективные выводы, не вытекающие из логики: «не знаю почему, но факт»

### Региональные маркеры (для формата H)

Каждый текст должен содержать 3-5 региональных маркеров. В формате H — встраиваем их в энциклопедический текст, без личного опыта:

- Конкретный город: «Игроки из Алматы и Астаны могут пополнить счёт через...»
- Конкретный банк: «Платформа поддерживает переводы через Kaspi и Halyk Bank»
- Конкретный провайдер: «При проблемах с доступом через Kcell или Beeline используйте зеркало»
- Конкретное спортивное событие: «В линии есть матчи КПЛ — например, “Астана” — “Кайрат”»
- Конкретная валюта с суммой: «Минимальная ставка — 100 тенге»

### Неправильно ✗ — формат A (1-е лицо, разговорный):

> Скачал APK, весит мегабайт 40 — нормально. У меня Samsung A54, встало без проблем. На Huawei знакомого тоже работает, хотя он жаловался что тормозит.

### Неправильно ✗ — канцелярит и шаблонность:

> Пополнение осуществляется мгновенно. Вывод средств занимает от 1 до 3 рабочих дней. Минимальный депозит составляет 1 000 тенге. Платформа предоставляет широкий спектр платёжных методов для удобства пользователей.

(Сухо, без подробностей, без местных банков, без конкретики — AI-детектор поймает.)

## КРИТИЧНО: объём текста (формат H — ЭНЦИКЛОПЕДИЯ)

**Главная страница: 3000-4000 слов. НЕ МЕНЬШЕ 3000.**
**Подстраницы: 1500-2500 слов. НЕ МЕНЬШЕ 1500.**
**Слот-обзоры: 1200-1800 слов.**

Формат H — длинная энциклопедия в стиле bc-game-brazil.com. Объём — это его суть. Если главная меньше 3000 слов — формат не соблюдён.

Правило: **полный охват темы.** На каждый аспект платформы — отдельная H2-секция с 200-350 словами и 1-2 изображениями. Сравнить, рассмотреть с разных сторон, дать пошаговую инструкцию, добавить таблицу параметров.

### Чтобы не получить спам и AI-детект на больших объёмах

- **Чередовать структуру внутри секций**: абзац → numbered list → абзац → таблица → абзац → bullet list. Не делать 4 абзаца подряд
- **Синонимы названия бренда** — обязательны (см. раздел про лимиты ниже): «платформа», «сервис», «казино», «букмекер», «контора», «сайт»
- **Перебрасывать ключевые слова** между H2-секциями, не повторять в каждой
- **Каждое предложение несёт факт или цифру** — нет пустых вводных
- **Burstiness** — длина предложений варьируется (5-30 слов в одной секции)

> Раньше (в формате A — Авторский блог) лимиты были: главная 1000-1400, подстраницы 500-800. Эти лимиты больше не актуальны для нового формата H.

## Антидетект AI — конкретные техники

### Проблема: AI пишет предсказуемо

AI-детекторы ловят **паттерн предсказуемости**: каждое следующее слово легко угадать из предыдущего. Человек пишет непредсказуемо.

### Техника 1: Ломать ритм предложений

```
ПЛОХО (AI-паттерн — все предложения 12-18 слов):
Платформа предлагает широкий выбор спортивных событий для ставок в реальном времени.
Коэффициенты обновляются быстро и находятся на конкурентном уровне.
Минимальная ставка составляет всего 100 тенге, что подходит для начинающих.

ХОРОШО (человек — от 3 до 25 слов):
Коэффициенты норм. На КПЛ маржа 4-5%, на АПЛ — 3%. Ставить можно от сотки — закинул
100 тенге на «Астану» в прошлые выходные и получил 215, не рекорд, но приятно. Правда
на live бывают задержки секунд 5-10, когда все одновременно ставят на голы.
```

### Техника 2: Начинать абзацы по-разному

Каждый абзац на странице должен начинаться с ДРУГОЙ конструкции:

- С факта: «Минимальный депозит — тысяча тенге.»
- С вопроса: «А что по выводу?»
- С личного: «Я проверял это в феврале.»
- С оценки: «Норм, но не идеал.»
- С действия: «Скачал APK, поставил за минуту.»
- С противопоставления: «Но вот с Halyk всё не так гладко.»

### Техника 3: Вставлять «шум»

Человеческий текст содержит «шум» — побочные мысли, отступления, эмоции:

```
ПЛОХО (AI — чистая информация):
Верификация занимает от 1 до 3 рабочих дней. Необходимо загрузить удостоверение личности
и селфи с документом. После проверки вывод средств будет доступен без ограничений.

ХОРОШО (человек — с шумом):
Верификацию проходил четыре дня, хотя обещали сутки. Загрузил удостоверение с ИИН,
селфи — ну знаете, такое ощущение что на допросе. Зато потом вывод пошёл без проблем.
Кстати, Kaspi Gold обрабатывается быстрее обычного Kaspi — не знаю почему, но факт.
```

### Техника 4: Конкретика вместо абстракции

Каждый абзац должен содержать минимум 1-2 конкретных элемента:

- Сумма: «5 000 тенге», «22 минуты», «3-4%»
- Дата: «в марте 2026», «в прошлую пятницу»
- Название: «Samsung A54», «Kaspi Gold», «Kcell»
- Место: «из Алматы», «на Арбате»

### Техника 5: Сокращать безжалостно

После написания абзаца — перечитай и убери:

- Все «который», «которая», «которое» — перефразировать
- Все «является», «представляет собой» — убрать
- Все «в рамках», «в целом», «в частности» — убрать
- Все предложения которые повторяют мысль предыдущего — убрать целиком

### Техника 6: Человеческие ошибки (КРИТИЧНО для антидетекта)

AI-детекторы ловят **безупречность**. Настоящий человек допускает ошибки — не случайные, а паттерные: те, что свойственны быстрому набору текста на русском.

#### Орфографические ошибки: 1-4 на страницу

Ошибки должны выглядеть как **опечатки при быстром наборе**, а не как незнание языка.

| Тип ошибки           | Пример                                               | Почему человеческая            |
| -------------------- | ---------------------------------------------------- | ------------------------------ |
| Пропуск буквы        | «регистраця» → регистрация, «прилжение» → приложение | Быстрый набор, палец проскочил |
| Перестановка букв    | «коэфициент» → коэффициент, «тенеге» → тенге         | Пальцы опередили друг друга    |
| Удвоение буквы       | «бонусс» → бонус, «каззино» → казино                 | Залипла клавиша                |
| Неправильная гласная | «скочать» → скачать                                  | Быстрый набор, не глядя        |
| -тся/-ться путаница  | «регистрироватся» → регистрироваться                 | Классика русского интернета    |

**Правила:**

- НЕ ставить ошибки в H1, title, description (SEO-критичные)
- НЕ ставить ошибки в первом предложении абзаца
- Ставить в СЕРЕДИНЕ длинных предложений или в конце абзаца
- НЕ больше 1 ошибки на абзац
- Ошибки должны быть в РАЗНЫХ словах (не повторять одну и ту же)

#### Пунктуационные «ошибки»: 2-3 на страницу

Ошибки должны быть **едва заметные**, внутри текста — не на краях абзацев. Читатель не должен споткнуться. Если ошибка бросается в глаза — она слишком грубая.

**ЗАПРЕЩЕНО (слишком грубо, сразу видно):**

- Запятая в конце абзаца вместо точки: «...хотя у других всё проходит за вечер — тут кому как,» ← НЕЛЬЗЯ
- Несколько запятых подряд вместо точек на весь абзац
- Запятая перед переносом строки / концом блока
- Отсутствие точки в конце абзаца

**РАЗРЕШЕНО (тонкое, человеческое):**

| Паттерн                                          | Пример                                                                                  | Почему незаметно                             |
| ------------------------------------------------ | --------------------------------------------------------------------------------------- | -------------------------------------------- |
| Пропуск запятой перед «что/который/где»          | «слот в котором можно купить бонусную игру»                                             | 80% людей так пишут, мало кто замечает       |
| Пропуск запятой после вводного                   | «В целом приложение работает стабильно» (нет запятой после «В целом»)                   | Частая ошибка даже у грамотных               |
| Лишняя запятая перед «и»                         | «скачал APK, и установил за минуту»                                                     | Люди ставят по интуиции                      |
| Тире вместо запятой в перечислении               | «Kaspi — Halyk — Jusan — все работают»                                                  | Разговорный стиль набора                     |
| Запятая внутри длинного предложения вместо точки | «Закинул 5000 тенге через Kaspi, деньги пришли минут через 20 и сразу поставил на КПЛ.» | Поток мысли, но предложение завершено точкой |
| Двойной пробел                                   | «деньги пришли за час»                                                                  | Опечатка при быстром наборе, почти невидимая |

**Правила:**

- Ошибка ВСЕГДА внутри предложения или между предложениями, НИКОГДА в конце абзаца
- Каждый абзац ВСЕГДА заканчивается точкой (или вопросительным/восклицательным знаком)
- Пропуск запятой — самый безопасный и незаметный паттерн, использовать чаще всего
- Лишняя запятая — второй по безопасности
- НЕ ставить пунктуационные ошибки в заголовках и списках

#### Пример с ошибками (правильно):

> Скачал APK через зеркало, весит мегабайт 40 — нормально. На Samsung A54 встало без проблем, а вот на Huawei знакомого были какие-то заморчки с установкой. Пришлось разрешить неизвестные источники, и перезагрузить телефон после этого всё заработало. Приложение в целом летает, разве что на старых телефонах может подтормаживть немного.

_(Здесь: «заморчки» — пропуск буквы; «подтормаживть» — перестановка; лишняя запятая перед «и перезагрузить»; пропуск точки между «телефон» и «после» — два предложения склеились. Всё внутри текста, конец абзаца — точка.)_

### Техника 7: Непоследовательность форматирования

AI всегда форматирует идеально одинаково. Человек — нет.

- Иногда писать числа цифрами, иногда словами: «5000 тенге» и «пять тысяч» в одном тексте
- Иногда «Kaspi», иногда «Каспи» — непоследовательная транслитерация
- Иногда «1xBet», иногда «1хбет» — в тексте оба варианта
- Иногда список через «-», иногда через «•», иногда просто через запятые
- Разная длина абзацев: один из 1 предложения, следующий из 5

### Техника 8: Энциклопедические переходы (для формата H)

В формате H между секциями и абзацами используем спокойные энциклопедические связки. Никаких «короче», «ну ладно», «кстати».

| ХОРОШО (формат H)                           | ПЛОХО (формат A — законсервирован) | ПЛОХО (канцелярит/AI)    |
| ------------------------------------------- | ---------------------------------- | ------------------------ |
| Помимо стандартных возможностей             | Ну и ещё момент —                  | Помимо этого             |
| Стоит обратить внимание на                  | Кстати                             | Стоит отметить, что      |
| Одной из ключевых особенностей является     | А что по...                        | Далее рассмотрим         |
| Среди других возможностей                   | Ладно, итого                       | Подводя итог             |
| Подробнее об этом — в разделе {ссылка}      | Если что — пишите                  | В заключение хотелось бы |
| Этот раздел заслуживает отдельного внимания | Тут такое дело                     | Необходимо подчеркнуть   |

### Техника 9: Развёрнутые FAQ-ответы (для формата H)

В формате H FAQ-ответы — длинные, энциклопедические, 3-6 предложений каждый. Без «лично у меня», без эмоций. С конкретными цифрами и пошаговыми инструкциями.

**Пример FAQ-ответа в формате H:**

> **Нужно ли проходить верификацию для игры в казино?**
>
> Для регистрации и начала игры верификация не требуется — достаточно создать аккаунт по email или номеру телефона. Однако для вывода средств и в случае подозрительной активности администрация платформы может запросить подтверждение личности. Процесс верификации занимает от 1 до 5 рабочих дней и включает загрузку фото удостоверения личности и селфи с документом. После прохождения верификации вывод средств обрабатывается быстрее, а лимиты увеличиваются.

> **Какие способы пополнения доступны для игроков из Казахстана?**
>
> Платформа поддерживает несколько способов пополнения. Через Kaspi Bank можно пополнить от 1 000 до 500 000 тенге, обработка занимает 1-5 минут. Halyk Bank принимает депозиты от 1 000 до 1 000 000 тенге, время зачисления — до 30 минут. Также доступны криптовалюты (USDT, Bitcoin, Ethereum) с минимальной суммой от 5 USDT и временем обработки 5-30 минут в зависимости от сети. Все транзакции обрабатываются через защищённые каналы с SSL-шифрованием.

### Техника 10: Неравномерная глубина секций

В формате H главная страница содержит 12-15 H2-секций. Не все секции должны быть одинаково подробными — это создаёт ощущение шаблонной AI-генерации.

Правила:

- 3-4 секции — **подробные** (250-350 слов): «Что такое {brand}», «Бонусы», «Способы оплаты», «Регистрация»
- 5-6 секций — **средние** (150-220 слов): «Лицензии и безопасность», «Поддержка», «Приложения»
- 2-3 секции — **короткие** (80-120 слов): «Верификация», «Финальный CTA»
- Промо-баннеры — стандартный шаблон, не считается

Это естественно: одни темы требуют развёрнутого описания (особенно бонусы), другие — короткого упоминания.

- «В целом приложение работает стабильно» (нет запятой после «В целом»)
- «Кстати вывод на Kaspi Gold быстрее» (нет запятой после «Кстати»)
- «Правда на live бывают задержки» (нет запятой после «Правда»)

**Лишняя запятая перед «и»:**

- «скачал APK, и установил за минуту»
- «пополнил через Kaspi, и сразу поставил»
- «зарегистрировался, и получил бонус»

**Склеенные предложения (пропуск точки внутри абзаца):**

- «Пришлось разрешить неизвестные источники и перезагрузить телефон после этого всё заработало.»
- «Верификация заняла четыре дня обещали сутки но ладно.»

**ЗАПРЕЩЕНО — грубые паттерны:**

- Запятая в конце абзаца вместо точки
- Весь абзац из одного предложения через запятые
- Отсутствие точки в конце абзаца

## Автоматическая проверка через text.ru API

После `npm run build` запускается скрипт автопроверки:

```bash
node _scaffold/check-text.cjs projects/{brand}/project_N
```

Скрипт:

1. Извлекает текст из каждого HTML в `dist/` (убирает header, footer, nav, теги)
2. Отправляет в API text.ru
3. Получает: заспамленность%, вода%, уникальность%
4. Выводит PASS/FAIL по каждой странице + топ повторяющихся ключей

Можно проверить одну страницу: `node _scaffold/check-text.cjs projects/{brand}/project_N bonus`

API-ключ хранится в `.env` (в корне workspace, в .gitignore).

AI-детект проверяется вручную: https://serpstat.com/ru/page/ai-content-detection/

## Самопроверка текста (обязательный чеклист) — формат H

После написания КАЖДОЙ страницы агент проверяет текст по этому чеклисту:

### Объём и структура (формат H)

- [ ] **Главная — 3000-4000 слов**, подстраницы — 1500-2500, слоты — 1200-1800
- [ ] **Минимум 12 H2-секций** на главной (рекомендация: 14-15)
- [ ] **Сводная таблица параметров** с эмодзи-маркерами в Hero/начале страницы
- [ ] **Минимум 1 большая таблица** на главной (VIP-уровни / бонусы на 4 депозита)
- [ ] **5-7 повторяющихся промо-баннеров** с бонусом на главной (после каждых 2-3 секций)
- [ ] **15-20 заглушек изображений** на главной (1-2 в каждой H2)
- [ ] **Numbered list** для пошаговых инструкций (регистрация, депозит, вывод)
- [ ] **Bullet list** для способов оплаты, преимуществ, security features
- [ ] FAQ в конце с 4-6 вопросами и развёрнутыми ответами 3-6 предложений
- [ ] Финальный блок с рейтингом 4.9/5

### Спам и вода

- [ ] Название бренда встречается не чаще 2 раз на абзац
- [ ] Нет 3+ одинаковых слов в одном предложении
- [ ] Нет 2 предложений подряд, начинающихся с одного слова
- [ ] Вводные конструкции — не более 1 на абзац
- [ ] Каждое предложение несёт факт, цифру или мнение (нет пустых связок)
- [ ] Синонимы бренда используются (платформа, сервис, казино, букмекер, контора, сайт)

### Натуральность (формат H)

- [ ] Длина предложений варьируется (5-30 слов, не одинаковая)
- [ ] Тон — 3-е лицо платформы + обращение «вы» к читателю
- [ ] **НЕТ** местоимений «я», «мне», «по-моему», «лично» в тексте (это формат A)
- [ ] **НЕТ** разговорных вставок «ну», «короче», «ладно», «блин» (это формат A)
- [ ] Конкретные цифры, даты, суммы в местной валюте — минимум 5 на страницу
- [ ] Региональные маркеры (банки, города, лиги) — 3-5 на страницу
- [ ] Энциклопедические переходы между секциями (не разговорные «короче»)

### Человеческие ошибки (общая техника 6 — применяется и к формату H, но дозированно)

- [ ] 1-3 орфографические опечатки на страницу (опечатки, не безграмотность)
- [ ] 1-2 тонкие пунктуационные «ошибки» ВНУТРИ текста (пропуск запятой перед «который», лишняя запятая перед «и»)
- [ ] Каждый абзац заканчивается точкой (НЕТ запятых на краях абзацев)
- [ ] Ошибки НЕ в H1, title, description и НЕ в первом предложении абзаца
- [ ] Есть лёгкая непоследовательность форматирования (числа цифрами и словами в разных местах)

### Лёгкость чтения

- [ ] Абзацы не длиннее 5-6 строк (на desktop)
- [ ] Есть чередование: абзац → numbered list → абзац → таблица → абзац → bullet list
- [ ] Подзаголовки H2 каждые 250-350 слов
- [ ] Нет «стены текста» — максимум 2 абзаца подряд без изображения, списка или таблицы

### Перелинковка (SEO)

- [ ] Минимум 5 внутренних ссылок на главной, 3 — на подстраницах
- [ ] Анкоры ссылок разнообразные и естественные (не «нажмите сюда»)
- [ ] Ссылки вплетены в текст органично (не вставлены в конце абзаца блоком)
- [ ] Ключевые страницы (регистрация, бонусы, казино) получают больше входящих ссылок
- [ ] Нет «сиротских» страниц (каждая имеет минимум 2 входящих ссылки)

## Внутренняя перелинковка — правила

### Принципы

Перелинковка — один из главных факторов ранжирования. Каждая ссылка должна выглядеть **естественно**, как будто автор упоминает другую тему по ходу рассказа.

### Количество ссылок на страницу

| Тип страницы                      | Мин. внутренних ссылок | На какие страницы                        |
| --------------------------------- | ---------------------- | ---------------------------------------- |
| Главная (index)                   | 5-8                    | На все основные подстраницы через секции |
| Подстраницы (registraciya и т.д.) | 3-5                    | На 2-3 тематически связанные + about     |
| Слот-обзоры                       | 2-3                    | На /casino + на 1-2 другие слоты         |
| About                             | 2-3                    | На главную + на 1-2 ключевые страницы    |

### Как вплетать ссылки в текст

**Правильно (органично):**

> Кстати, если ещё не зарегистрировались — у меня есть [пошаговая инструкция](/registraciya), там всё по шагам расписал.

> Вывод на Kaspi подробнее разбирал в [обзоре личного кабинета](/lichnyy-kabinet) — там же про верификацию.

> Этот слот похож на [Sweet Bonanza](/sweet-bonanza), но множители тут работают иначе.

**Неправильно (неестественно):**

> Также рекомендуем ознакомиться: [Регистрация](/registraciya) | [Бонусы](/bonus) | [Казино](/casino)

### Анкоры ссылок

Анкор (текст ссылки) должен быть разнообразным и включать ключевые слова:

| Вместо         | Использовать                   |
| -------------- | ------------------------------ |
| «нажмите сюда» | «инструкция по регистрации»    |
| «подробнее»    | «как я скачивал приложение»    |
| «ссылка»       | «обзор Sugar Rush»             |
| «тут»          | «в разборе бонусной программы» |

Каждый анкор на сайте должен быть уникальным — не использовать одинаковый текст для ссылок на разные страницы.

## Активный формат — H (Премиум-энциклопедия в стиле BC.Game)

Все новые проекты пишутся **только в формате H**. Стили авторов (`bio_style`) — `casual` / `analytical` / `enthusiast` / `skeptic` — больше не применяются, потому что в формате H нет персоны автора.

### Формат H — обороты, которые ИСПОЛЬЗОВАТЬ

**Платформа в 3-м лице:**

- «{brand} предлагает игрокам широкий выбор...»
- «Платформа поддерживает более 15 криптовалют»
- «{brand} Casino работает на рынке с 2017 года»
- «Сервис обеспечивает быстрые транзакции»
- «Букмекер располагает лицензией Curaçao»

**Прямое обращение к читателю:**

- «Вы можете легко пополнить счёт через...»
- «Зарегистрируйтесь сегодня и получите бонус 200%»
- «Введите промокод в специальное поле»
- «Выберите удобный способ оплаты»

**Маркетинговые обороты:**

- «Зарегистрируйтесь сегодня и получите...»
- «Заберите бонус до {сумма}»
- «Сделайте депозит за 7 минут»
- «Играйте на любом устройстве»

**Энциклопедические переходы:**

- «Одной из ключевых особенностей платформы является...»
- «В дополнение к этому, {brand} предлагает...»
- «Помимо стандартных возможностей, у пользователей есть доступ к...»
- «Стоит обратить внимание на...»
- «Подробнее об этом — в разделе {ссылка}»

### Формат H — обороты, которые ЗАПРЕЩЕНО использовать

- «Я», «лично мне», «по-моему», «проверял сам» — это формат A (личный блог), законсервирован
- «Мы предлагаем», «наши клиенты», «у нас есть» — это формат B (корпоративный), законсервирован
- Разговорные «ну», «короче», «блин», «вот честно», «лично мне не зашло» — формат A
- «Согласно данным из открытых источников» — это формат D (с дисклеймерами), законсервирован
- Короткие маркетинговые слоганы из 1-2 слов вместо абзацев — формат E (лендинг), законсервирован

### Особенности формата H

- Допустимы **эмодзи в сводной таблице параметров** (✅ 📃 🎮 🃏 🎲 🎰 🔢 🎁 💳 💰 ⌛ 📱 📞) — но не в основном тексте
- Допустимы **бейджи доверия**: «Проверено», «Использовано 6 минут назад», «Подробнее»
- **Промо-баннер с бонусом** повторяется 5-7 раз на главной (с одинаковой структурой, но разными формулировками заголовка)
- **Длинные абзацы** допустимы и желательны (4-6 предложений)
- **Таблицы** — обязательны (минимум 2 на главной)
- **Numbered lists** для пошаговых инструкций (4-7 шагов)
