## Памятка для нового проекта (формат H)

Для каждого нового проекта генератор `_scaffold/create-project.cjs` теперь автоматически проставляет:

- `content_format`: `"H"`
- `visual_style`: один из `["premium-encyclopedia", "casino-glam", "dark-premium"]`
- `sections_order`: `"fixed"` (порядок секций фиксированный для формата H)
- `bonus`: объект с цифрами бонуса (primary_percent, freespins, max_amount, first_n_deposits_total_percent, wager)
- Без полей `author` и `bio_style` — в формате H персона автора не используется

При создании проекта в реестре в колонках «Автор», «Город», «Стиль» ставим `—` (для формата H они не используются), а в колонке «Формат» — `H: Премиум-энциклопедия`.
